Career path style previews

Each card is a looping animation: path emerges on the left, grows right with branches, then the left side fades and a new path starts. Click any card to restart its animation.

A — Sparse orthogonal
Few long branches. Strict grid. Thin stroke. Minimal and clean.
B — Root system
More forks, shorter tips. Still orthogonal. Denser branching near the end.
C — Soft curves
Bezier curves instead of hard grid. Organic root feel. Not locked to squares.
D — Single trunk + rare forks
One dominant path with only 2–3 careful branches. Very restrained.
E — Circuit trace
Right angles only. Longer horizontal runs. Technical / schematic look.
F — Fading trail
Orthogonal path with a soft trailing fade behind the leading tip (comet style).
